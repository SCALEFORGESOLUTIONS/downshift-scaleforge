# downshift-scaleforge

Public front ends for Downshift products: landing pages and decks meant to be seen
outside the company.

## Contents

| File | What it is |
|---|---|
| `jamwise.index.html` | JamWise landing page |
| `jamwise.deck.html` | JamWise deck |
| `rivalize.landingpage.html` | Rivalize landing page |
| `v3-IN.rivalize.deck.html` | Rivalize deck, inbound |
| `v3-OUT.rivalize.deck.html` | Rivalize deck, outbound |
| `v2-sketchie.landingpage.index.html` | Sketchie landing page |
| `v2-sketchiepitchdeck.html` | Sketchie pitch deck |
| `nojekyll` | Tells GitHub Pages to serve files as-is |

## What does not belong here

This repository is public. Anything confidential, internal or unshipped belongs in
`downshift-archive`, which is private: client dossiers, working context documents, cost
and margin figures, credentials, environment hostnames, QA records, and defects for
products that have not launched.

Removing a file from this repository does not remove it from the repository's history.
Anything that was ever committed here stays readable through the commit log and through
anything that cloned or forked it. Treat a commit to this repository as publication.
