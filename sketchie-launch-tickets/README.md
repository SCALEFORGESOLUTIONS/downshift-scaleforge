# Sketchie Launch Tickets

One-page view of the Sketchie launch plan: 2 epics (L1 Launch Prep, L2 Launch Week) and 25 tickets, each with one owner, one due date and one "done when" line.

The whole site is `index.html`. It has no build step and no dependencies apart from Google Fonts.

## Before you share the link

This repository is public and so is the page. It lists internal owners, dates and launch
decisions. The `noindex` tag keeps search engines from listing it, but it does not hide it,
and a commit here stays in the repository's history permanently.
